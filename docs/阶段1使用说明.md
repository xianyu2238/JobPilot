# 阶段 1 使用说明

## 安装与启动

在项目根目录执行（本机已安装并验证 Python 3.14.4）：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt --index-url https://pypi.org/simple
```

已有 `.env` 不要覆盖，确认以下配置，密钥只保存在本地：

```dotenv
JOBPILOT_LLM_BASE_URL=https://aihubmix.com/v1
JOBPILOT_LLM_API_KEY=你的真实密钥
JOBPILOT_LLM_MODEL=qwen3.8-flash
JOBPILOT_VISION_MODEL=qwen3.8-flash
JOBPILOT_OCR_CONFIDENCE_THRESHOLD=0.85
JOBPILOT_OCR_THREADS=4
```

`VISION_MODEL` 只用于手动选择的备用视觉识别；默认本地 OCR 不需要 API Key。模型结构化和建议分析需要文本模型，也兼容 `AIHUBMIX_API_KEY`，与 `JOBPILOT_LLM_API_KEY` 选择一个填写。模型地址末尾不写 `/chat/completions`。

两个终端分别启动：

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

```powershell
.\.venv\Scripts\python.exe -m streamlit run frontend/streamlit_app.py --server.address 127.0.0.1
```

页面：http://127.0.0.1:8501 ，接口文档：http://127.0.0.1:8000/docs 。按 Ctrl+C 停止。仅运行单 worker。

## 使用流程

1. 上传 PDF、PNG、JPG/JPEG，默认选择“本地 OCR”，点击“解析简历”。图片在本机识别，文本型 PDF 直接提取文字。
2. 识别文字保存在后端内存，页面直接展示五类可编辑表单，不展示常规 OCR 提示和额外整理按钮。
3. 点击解析后自动整理为五类信息，无需额外勾选模型发送许可。失败时可在顶部重新点击“解析简历”，或直接手动填写；相同文件可复用已保存的识别文字。
4. 左侧依次编辑个人信息、教育背景、实习经历、项目经历和个人技能。教育、实习和项目使用独立表单与多行文本框；个人技能集中在一张可增删行的表中，仅显示“技能”和“详细介绍”，不展示来源或掌握情况。
5. 点击“保存修改”，再勾选核对确认。未保存的修改会阻止分析；保存会清除确认和旧分析。后续建议使用已保存的新版本。
6. 右侧粘贴 JD 并点击“开始分析”，下方显示修改建议与学习计划。岗位要求抽取功能已移除。

原文件和 OCR 原文保持不变；修改项标为“用户修改”，不伪装成原文件证据。首次 OCR 初始化较慢，后续复用同一引擎；相同文件在临时记录有效期间可复用识别结果。清空按钮删除本次后端记录，最后一份引用删除后不再保留该识别缓存。

长经历允许每项引用最多 64 个不同原文片段，自动去重并保留全部有效引用；模型输出与最终证据存储使用同一上限。结构格式失败时，页面会提示具体栏目和错误类型，已识别文字仍可用于重试或手动填写。

## 新增与主要修改文件

| 文件 | 功能 |
| --- | --- |
| `app/services/ocr_service.py` | 本地 RapidOCR、阅读顺序、文字框和置信度 |
| `frontend/resume_editor.py` | 逐条表单、多行文本、增删、保存与未保存提示 |
| `app/services/document_service.py` | 默认本地识别，手动选择远程视觉备用 |
| `app/services/resume_service.py` | 分开保存文字与结构化结果、编辑合并、原文证据回填 |
| `app/api/resumes.py` | 上传、结构化、更新、确认、预览与删除接口 |
| `app/repositories/memory.py` | 临时结果复用、版本冲突检查、修改后重新确认 |
| `app/schemas/business.py` | 五类结构、编辑输入、OCR 文字框与版本号 |
| `frontend/streamlit_app.py` | 五类表单、编辑和建议流程 |
| `tests/test_ocr_service.py`、`test_resume_editing.py` | OCR、保留失败成果、缓存、编辑保存与版本测试 |

模型提示词、匹配服务、配置、依赖和已有接口/页面测试也已同步更新。

## 当前限制与验证

- 默认文件上限 5 MiB、PDF 5 页、图片 1200 万像素、文字 30,000 字符；JD 最多 15,000 字符。
- 数据保存在内存，默认 20 份简历、一小时过期；重启或热重载会清空，不具备账号隔离。
- OCR 与模型可能漏字或错序，置信度不是事实准确率；复杂双栏仍需人工核对。
- 五类信息修改只更新本次结构化记录，不修改原始 PDF/JPG，也不生成新的简历文件。
- 默认模型单次等待 90 秒、每个整理操作预算 300 秒；模型速度有波动，文字保留后可单独重试。
- 已通过本地 OCR 实测：指定密集 JPG 首次约 3.47 秒、复用引擎约 2.13 秒；经 API 完整上传识别约 3.93 秒。模型整理用合成简历验证，五类结构返回成功，约 11.09 秒。两项不是同一文件的端到端总耗时。
- 修复长经历引用限制后，同一密集 JPG 已完成真实端到端验证：本地 OCR 约 5.36 秒，模型整理约 23.96 秒，一次成功；两条实习分别保留 19、11 个原文引用，项目保留 6 个。54 项回归测试通过。耗时受当时机器和模型服务状态影响。
- 自动化测试覆盖编辑、保存、重新确认和新版本分析；完整九组人工准确性验收与浏览器视觉检查仍待完成。

运行测试和生成合成样例：

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe scripts/generate_samples.py
```
