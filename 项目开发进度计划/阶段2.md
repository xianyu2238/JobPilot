# 阶段 2：接入 LangGraph 单 Agent

> 每个阶段以“交付成果 + 验收标准”判断是否完成，不设置周数或日期。建议优先完成阶段 0–3 后再考虑增强功能。

**目标：** 将已有业务能力封装为工具，完成 Agent 决策闭环。

**任务：**

- [ ] 定义 Agent State 和节点执行流程。
- [ ] 封装简历读取、JD 解析、岗位匹配等工具。
- [ ] 接入支持工具调用的 LLM。
- [ ] 实现 Agent → ToolNode → Agent 条件循环。
- [ ] 加入最大工具调用步数、超时、异常捕获。
- [ ] 记录工具调用轨迹，便于调试与演示。

**交付物：** `/api/agent/chat`，支持至少两种不同工具的动态选择。

**验收标准：** 能从自然语言任务中选择合理工具；工具失败不会导致无提示崩溃；不会无限循环；没有工具需求时能直接回答。
