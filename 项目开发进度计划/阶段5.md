# 阶段 5：质量、性能与安全

> 每个阶段以“交付成果 + 验收标准”判断是否完成，不设置周数或日期。建议优先完成阶段 0–3 后再考虑增强功能。

**目标：** 从“能跑”提高到“可以解释系统可靠性”。

**任务：**

- [ ] 补齐 Service 单元测试和 Agent 工具模拟测试。
- [ ] 建立 20–30 条真实或脱敏测试任务，形成评估集。
- [ ] 统计任务完成率、工具调用成功率、解析格式合格率和请求耗时。
- [ ] 完善 LLM/API 超时、重试策略及成本限制。
- [ ] 添加日志、请求 ID、关键错误排查路径。
- [ ] 检查上传安全、敏感信息与数据删除逻辑。

**交付物：** 测试报告、评估结果、关键边界案例。

**验收标准：** 核心 API 测试通过；主要失败路径有明确返回；README 记录测试方法和实际测量值，不能编造指标。
