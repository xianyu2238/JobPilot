# 阶段 4：Agent 增强功能（按价值选择）

> 每个阶段以“交付成果 + 验收标准”判断是否完成，不设置周数或日期。建议优先完成阶段 0–3 后再考虑增强功能。

**目标：** 增强 Agent 的实际业务价值，不要求全部完成。

**可选任务：**

- [ ] 接入 Web Search Tool，结果附来源链接。
- [ ] 增加模拟面试 Agent 的多轮追问与结构化反馈。
- [ ] 使用 LangGraph 持久化机制管理对话状态。
- [ ] 增加 SSE 流式答复和工具执行状态展示。
- [ ] 如有真实知识库场景，再增加 pgvector RAG。

**交付物：** 至少一项可展示的高级能力。

**验收标准：** 搜索结论可追溯来源；模拟面试有连贯上下文；若启用 RAG，回答能引用检索到的材料；新增功能有基本异常测试。
