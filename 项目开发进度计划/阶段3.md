# 阶段 3：数据持久化与可演示界面

> 每个阶段以“交付成果 + 验收标准”判断是否完成，不设置周数或日期。建议优先完成阶段 0–3 后再考虑增强功能。

**目标：** 做出完整的、可重复演示的 MVP。

**任务：**

- [ ] 添加 PostgreSQL、SQLAlchemy、Alembic。
- [ ] 持久化简历、岗位、分析结果与会话数据。
- [ ] 制作 Streamlit 简历上传、JD 匹配和 Agent 对话页面。
- [ ] 统一 API 响应与异常处理。
- [ ] 增加基础集成测试和演示数据。

**交付物：** 具备前后端交互、数据保存能力的 MVP。

**验收标准：** 可以演示“上传简历 → 输入 JD → 匹配分析 → Agent 追问”的完整流程；重启服务后数据仍可读取。
