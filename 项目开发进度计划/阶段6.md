# 阶段 6：部署、文档与实习简历包装

> 每个阶段以“交付成果 + 验收标准”判断是否完成，不设置周数或日期。建议优先完成阶段 0–3 后再考虑增强功能。

**目标：** 形成可给面试官打开、运行、理解的作品。

**任务：**

- [ ] 编写 Dockerfile 与 Docker Compose。
- [ ] 配置一键本地启动与必要环境变量。
- [ ] 完善 README：功能截图、架构图、技术栈、快速启动、接口示例。
- [ ] 绘制 Agent 调用链和数据库关系图。
- [ ] 准备项目演示视频或 GIF、面试讲解提纲。
- [ ] 总结技术难点、权衡与真实测试结果。

**交付物：** GitHub 仓库、演示材料、可写进简历的项目描述。

**验收标准：** 新环境可按文档跑通核心流程；面试时能解释 Agent State、工具调用、后端分层、异常恢复和数据库设计。
