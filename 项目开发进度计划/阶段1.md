# 阶段 1：简历解析与 JD 匹配（基础 MVP）

> 每个阶段以“交付成果 + 验收标准”判断是否完成，不设置周数或日期。建议优先完成阶段 0–3 后再考虑增强功能。

**目标：** 完成不依赖 Agent 决策的业务核心。

**任务：**

- [ ] 实现 PDF 上传、文件格式与大小校验。
- [ ] 利用 PyMuPDF 提取文本，处理空文本与异常文件。
- [ ] 使用 LLM + Pydantic 抽取简历结构化信息。
- [ ] 实现 JD 要求抽取、技能比对与差距分析。
- [ ] 输出岗位技能、简历证据、缺失技能和改进建议。
- [ ] 编写 API 测试与典型样例。

**交付物：** `/api/resumes` 与 `/api/jobs/match` 可正常工作。

**验收标准：** 使用至少 3 份脱敏简历和 3 份 JD 进行测试；结构化结果通过模式验证；无法解析的 PDF 返回清晰错误；匹配结论可找到原文证据。
